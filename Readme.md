# キャラセレ記憶 (CHARA SELECT MEMORY)

対戦ゲームのキャラクター選択画面を、記憶だけで復元するブラウザゲームです。
空の盤面にキャラ名を並べるか、直接打ち込んで、正確さと速さを競います。

非公式のファンメイド作品です。各タイトルの権利は権利者に帰属します。
画像・ロゴ・フォント等の素材は一切使用していません。

## 公開手順 (GitHub Pages)

依存ライブラリもビルドも不要です。`index.html` を置くだけで動きます。

1. GitHub で新しいリポジトリを作る（Public）
2. `index.html` と `README.md` をアップロードしてコミット
3. Settings → Pages を開く
4. Source を **Deploy from a branch**、Branch を **main / (root)** にして Save
5. 数分待つと `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開される

更新したいときは `index.html` を編集してコミットすれば、自動で反映されます。

## 遊び方

- **並べる** … キャラ名が全部下に並ぶ。タップで選んでマスに置くか、ドラッグして置く
- **記入する** … 選択肢なし。マスを選んで名前を直接入力する

スコアは `正解数 × 100 + 時間ボーナス` です。
時間ボーナスは `(300秒 - 経過秒) × 正答率` で、300秒を超えると 0 になります。

自己ベストはブラウザの localStorage に保存されます。端末をまたいだ共有はしません。

## データの追加・修正

アプリ内の「データを編集」から JSON を直接書き換えて、その場で反映・確認できます。
確定したら「保存」で書き出し、`index.html` 内の `const DATA = [...]` に貼り戻してください。

### 盤面の書き方

`parts` に「行」と「円」を上から順に積みます。

```jsonc
{
  "id": "example",
  "name": "作品名",
  "meta": "2005 / 25名",
  "verified": true,
  "parts": [
    { "type": "row", "w": 470, "names": ["A", "B", "C"] },

    { "type": "circle", "size": 470, "core": "AREA\nRANDOM",
      "rings": [
        { "r": 172, "from": 0, "names": ["D", "E", "F"] },
        { "r": 92,  "at": [-12, 12, 90], "names": ["G", "H", "I"] }
      ]
    },

    { "type": "row", "w": 470, "names": ["I", "J", "K"] }
  ]
}
```

| キー | 対象 | 意味 |
|---|---|---|
| `w` | row | 行の最大幅(px)。省略すると横いっぱいに広がる |
| `size` | circle | 描画領域の一辺(px) |
| `core` | circle | 中央の円に出す文字。`\n` で改行 |
| `r` | ring | 中心からの距離(px) |
| `from` | ring | 開始角度。0 が真上で時計回り。等間隔に並ぶ |
| `at` | ring | 角度の配列。1枚ずつ位置を決める。`from` より優先 |
| `names` | 共通 | 並び順そのもの |
| `verified` | 作品 | `false` にするとタイトル画面に ⚠ が付く |

### 等間隔でない円の作り方

実際のキャラ選択画面は、円周上に均等配置されていないことが多いです。
そういう場合は `from` の代わりに `at` で1枚ずつ角度を指定します。

```
     -12  12          上に2枚
 306          54
 282          78      左右に4枚ずつ
 258         102
 234         126
    168  192          下に2枚
```

同じ `r` の ring を複数書けば、弧を離れた位置に置くこともできます。
角度の目安は、真上が 0、右が 90、下が 180、左が 270 です。
タイル1枚が占める角度はおおよそ `66 / r × 57` 度なので、
`r` が小さいほど間隔を広く取る必要があります。

キャラ名は `"ソル|ソルバッドガイ|そる"` のように書くと、`|` 以降が記入モードの
別解として通ります。表示に使われるのは先頭だけです。

判定時は全角半角・ひらがなカタカナ・中黒やハイフンの有無を吸収するので、
そこまでの表記ゆれを別解に登録する必要はありません。
