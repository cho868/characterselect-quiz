# キャラセレ記憶 (CHARA SELECT MEMORY)

対戦ゲームのキャラクター選択画面を、記憶だけで復元するブラウザゲームです。
空の盤面にキャラ名を並べるか、直接打ち込んで、正確さと速さを競います。

非公式のファンメイド作品です。各タイトルの権利は権利者に帰属します。
画像・ロゴ・フォント等の素材は一切使用していません。

## 遊び方

- **並べる** … キャラ名が全部下に並ぶ。タップで選んでマスに置くか、ドラッグして置く
- **記入する** … 選択肢なし。マスを選んで名前を直接入力する

スコアは `正解数 × 100 + 時間ボーナス` です。
時間ボーナスは `(300秒 - 経過秒) × 正答率` で、300秒を超えると 0 になります。

自己ベストはブラウザの localStorage に保存されます。端末をまたいだ共有はしません。

## 構成

`index.html` 1ファイルだけで動きます。ビルドも依存ライブラリもサーバーも不要です。

```
index.html    本体（HTML / CSS / JS / データすべて）
README.md
LICENSE
.gitignore
```

## 公開手順 (GitHub Pages)

1. `index.html` をリポジトリのルートに置いてコミットする
2. Settings → Pages を開く
3. Source を **Deploy from a branch**、Branch を **main / (root)** にして Save
4. 数分待つと `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開される

更新は `index.html` を編集してコミットするだけで自動的に反映されます。
反映されて見えないときはブラウザのキャッシュなので、Ctrl+F5 で再読み込みしてください。

## データの追加・修正

`index.html` 内の `const DATA = [...]` を書き換えます。
GitHub 上でファイルを開き、鉛筆アイコンから直接編集してコミットもできます。

### 盤面の書き方

`parts` に「行」と「円」を上から順に積みます。

```jsonc
{
  "id": "example",
  "name": "作品名",
  "meta": "2005 / 25名",
  "verified": true,
  "parts": [
    { "type": "row", "w": 470, "names": ["A", "B", "C"] },

    { "type": "circle", "size": 580, "core": "AREA\nRANDOM",
      "rings": [
        { "r": 250, "from": 0, "names": ["D", "E", "F"] },
        { "r": 168, "at": [-12, 12, 90], "names": ["G", "H", "I"] }
      ]
    }
  ]
}
```

| キー | 対象 | 意味 |
|---|---|---|
| `w` | row | 行の最大幅(px)。省略すると横いっぱいに広がる |
| `size` | circle | 描画領域の一辺(px) |
| `core` | circle | 中央の円に出す文字。`\n` で改行 |
| `r` | ring | 中心からの距離(px) |
| `from` | ring | 開始角度。0 が真上で時計回り。等間隔に並ぶ |
| `at` | ring | 角度の配列。1枚ずつ位置を決める。`from` より優先 |
| `names` | 共通 | 並び順そのもの |
| `verified` | 作品 | `false` にするとタイトル画面に ⚠ が付く |

### 等間隔でない円の作り方

実際のキャラ選択画面は、円周上に均等配置されていないことが多いです。
そういう場合は `from` の代わりに `at` で1枚ずつ角度を指定します。
GGXX SLASH の中央リングは上2枚・右4枚・下2枚・左4枚のかたまりで、こう置いています。

```
     -12  12
 306          54
 282          78
 258         102
 234         126
     168  192
```

同じ `r` の ring を複数書けば、離れた位置に弧を置けます。
角度の目安は、真上が 0、右が 90、下が 180、左が 270 です。
タイル1枚が占める角度はおおよそ `66 / r × 57` 度なので、
`r` が小さいほど間隔を広く取る必要があります。

### 表記ゆれ

キャラ名を `"ソル|ソルバッドガイ|そる"` と書くと、`|` 以降が記入モードの別解として
通ります。表示に使われるのは先頭だけです。

判定時に全角半角・ひらがなカタカナ・中黒やハイフンの有無は自動で吸収するので、
その程度の違いを別解に登録する必要はありません。

## セキュリティについて

静的サイトなので、サーバーもデータベースもユーザー登録もありません。
入力された内容はブラウザの外に一切送信されず、自己ベストも端末内に留まります。

コードは誰でも読めますが、これは公開リポジトリだからではなく、ブラウザが
`index.html` の全文をダウンロードして動かす仕組みだからです。リポジトリを
非公開にしても「ページのソースを表示」で同じものが読めます。

**したがって、このリポジトリには秘密情報を一切置かないでください。**
API キー、パスワード、アクセストークン、個人情報などを書き込むと、そのまま
全世界に公開されることになります。

キャラの並び（＝答え）もソースに書かれているため、その気になれば読めます。
記憶ゲームの性質上これは避けられないので、仕様として割り切っています。

外部リソースは読み込んでいません。CSP で `default-src 'none'` を指定し、
ネットワークアクセスそのものを禁止しています。
